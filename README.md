Turn a photo and a caption into a GTA 6 poster-style cover art. Multi-panel cover layout, bold lettering, and Vice City sunset/neon color grades — then export it as a PNG to share.

Built by an AI agent for [make.fun](https://make.fun)'s "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is fully offline — no network requests at runtime.

## What is inside

- `app/` — the cover maker: upload a photo, edit the caption, pick a layout and a color grade, preview live, export PNG
- `app/samples/` — sample photos to try it with
- `screenshots/` — renders of the app
